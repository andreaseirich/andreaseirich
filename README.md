## 🚀 Featured Projects

### 📅 [Preceptly](https://github.com/andreaseirich/preceptly) — tutoring management platform

Scheduling with conflict detection (time overlaps, travel time, contract quotas), invoicing with PDF export, public booking, a parent/student portal, video lessons, calendar sync and optional AI-assisted lesson plans. Started as a CodeCraze Hackathon 2025 submission and now runs live with Stripe subscriptions.

**Stack:** Django · PostgreSQL · Django Channels & Redis · WebRTC · Stripe · Docker · Railway<br>
🌐 [preceptly.de](https://preceptly.de) · 🎥 [Demo video](https://youtu.be/YUsSuPgR1XQ) · 📄 [Case study](https://andreaseirich.github.io/preceptly.html)

### 🍯 [Honey Treasures](https://github.com/andreaseirich/honey-treasures) — online shop for a family apiary

E-commerce system for my family's beekeeping business: product catalog, cart with volume discounts, order and stock management, and a role-based admin backend with analytics. In production and self-hosted on a Raspberry Pi. The public repository contains the technical documentation.

**Stack:** Django · SQLite · Nginx · Gunicorn · Let's Encrypt<br>
🌐 [honey-treasures.com](https://honey-treasures.com) · 📄 [Case study](https://andreaseirich.github.io/honey-treasures.html)

### 🛡️ [ChatCompanion](https://github.com/andreaseirich/ChatCompanion) — privacy-first chat safety assistant

Offline tool that helps young people (ages 10–16) recognize manipulation, bullying, pressure and grooming patterns in chat conversations and explains them in plain language — no uploads, no telemetry. Rules-first detection with optional local ML models. Built for the Code Spring hackathon.

**Stack:** Python · Streamlit · sentence-transformers · ONNX Runtime · pytest<br>
🎥 [Demo video](https://youtu.be/5ZxlkHXds_0) · 📄 [Case study](https://andreaseirich.github.io/chatcompanion.html)

### 🚲 RADhuus Nortrup — client website

Static, GDPR-compliant website for a bicycle shop in Lower Saxony: no cookies or trackers, dark/light mode, photo gallery and Schema.org data. Image payload reduced from ~38 MB to ~8 MB.

**Stack:** HTML · CSS · JavaScript<br>
🌐 [radhuus-nortrup.de](https://radhuus-nortrup.de) · 📄 [Case study](https://andreaseirich.github.io/radhuus-nortrup.html)

### 💻 AndiCode.de — freelance website

Single-page website for my freelance web development services, past projects and tech stack.

**Stack:** HTML · Tailwind CSS · JavaScript<br>
🌐 [andicode.de](https://andicode.de) · 📄 [Case study](https://andreaseirich.github.io/andicode.html)
